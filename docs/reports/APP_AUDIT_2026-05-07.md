## 1. API Routes Architecture (app/api)

### ✅ Strengths

**Thin Controllers Pattern:**
- Mayoritas API routes sudah menggunakan service layer dengan baik
- Contoh baik: `app/api/bandwidths/route.ts`, `app/api/registrations/route.ts`
- Authorization logic sudah di `hasPermission()` sebelum call service
- Error handling menggunakan `ApiErrors.*` pattern yang konsisten

**Sample Good Pattern:**
```typescript
// app/api/bandwidths/route.ts
export async function GET(req: NextRequest) {
  const session = await getServerSession(authOptions);
  if (!session?.user) return ApiErrors.unauthorized();
  
  if (!(await hasPermission("bandwidth:read"))) {
    return ApiErrors.forbidden();
  }
  
  const bandwidths = await bandwidthRouteService.getBandwidths(req.url, session);
  return apiSuccess(bandwidths);
}
```

**No Direct Prisma Usage:**
- Tidak ditemukan `await prisma.` di API routes
- Semua database access melalui service/repository layer ✅

### ⚠️ Areas for Improvement

**Large API Routes (>150 lines):**

Top 10 largest routes yang perlu review:

1. `app/api/inventory/gudang/[id]/route.ts` - **194 lines**
   - Issue: 3 HTTP methods (GET, PUT, DELETE) dalam 1 file
   - Recommendation: Masih acceptable karena cohesive (CRUD operations untuk 1 resource)
   - Action: Keep as-is, sudah menggunakan service layer dengan baik

2. `app/api/inventory/opname/route.ts` - **190 lines**
3. `app/api/admin/workorders/[id]/route.ts` - **188 lines**
4. `app/api/admin/salary/route.ts` - **188 lines**
   - Issue: Complex authorization logic di route level (site-level isolation)
   - Recommendation: Extract authorization logic ke middleware atau service
   - Action: Consider refactor authorization ke `lib/rbac.ts`

5. `app/api/pelanggan-ppp/[id]/usage/route.ts` - **185 lines**
6. `app/api/network/alerts/[id]/route.ts` - **182 lines**
7. `app/api/mobile/work-orders/[id]/partners/route.ts` - **181 lines**
8. `app/api/integrations/mixradius/test/route.ts` - **175 lines**
9. `app/api/finance/expenses/[id]/route.ts` - **175 lines**
10. `app/api/mobile/work-orders/[id]/return/route.ts` - **171 lines**

**Authorization Logic in Routes:**

File `app/api/admin/salary/route.ts` memiliki site-level isolation logic yang kompleks:

```typescript
// Lines 50-62
let siteId = searchParams.get("siteId") || undefined;
const isSiteOnly = await hasPermission("salary:site_only");

if (isSiteOnly && !sessionUser.isSuperAdmin) {
  if (siteId && siteId !== sessionUser.siteId) {
    return ApiErrors.forbidden(
      "Anda hanya diperbolehkan melihat data gaji di site Anda sendiri",
    );
  }
  siteId = sessionUser.siteId as string;
}
```

**Recommendation:** Extract ke `lib/rbac.ts` sebagai `enforceSiteIsolation()` helper.
